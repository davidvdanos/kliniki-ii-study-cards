# Κλινική Ψυχολογία ΙΙ - Study Cards

Static study site for Κλινική Ψυχολογία ΙΙ revision.

## Περιεχόμενα

- Interactive study cards in `index.html`
- Generated note pages in `notes/`
- Downloadable Word notes in `downloads/`
- Source-driven note page builder: `build_notes_pages.py`

## Rebuild

Run:

```powershell
python build_notes_pages.py
```

Then commit and push the regenerated `notes/` and `downloads/` folders.
